# Reporting and export

Moved verbatim from `CLAUDE.md` (The subsystems) on 2026-10-19, so `CLAUDE.md` stays short. `CLAUDE.md` links here; keep this file current in the same commit as any change to what it describes.

- **Reporting / export tooling** (`/reports`, `ReportsPage.jsx` + pure `src/reporting.js`; staff-only, in the avatar STAFF menu). Reads **both hour sources** — attendance_events-derived sessions (capped, via `sessionsFromEvents`) and verified `logged_hours` — and flattens them into export rows carrying the `wasCapped` (derived), `manual_entry`, and `review` (pending/voided session_reviews) flags. **No schema change**: hours are tied to calendar events by **date/time window match**, not an explicit link column — `buildRows`/`matchEvent` attribute an attendance session to the earliest event whose `[starts_at, ends_at]` window it overlaps, and a logged entry to the earliest event whose LA-local date span contains its date (the check-in fast paths don't know their event, so a stored link would drift). Three tabs: **Per-event rollups** (`rollupByEvent` — per-event category split + total + distinct member count, e.g. per competition weekend / build day); **Exports** (filter by student / date range / category / event; per-student or team-wide; CSV download via `rowsToCsv` + print-to-PDF via `exportHtml`; flags as columns); **Service-hour letters** (`letterData`/`letterHtml` — per student/volunteer for a date range: name, total, category breakdown, range, team identifier "Techmen — FRC Team 5669 / Don Bosco Technical Institute", itemized appendix + preparer + mentor signature line for verifiability; service categories default to volunteer/outreach, adjustable). **PDF = a print window** (`window.open` + embedded print CSS + `window.print()`) so it's dependency-free, offline, and lets the browser "Save as PDF" — no PDF lib added. Letters/rollups use official hours (exclude review-flagged); the raw export includes everything with the flag columns.

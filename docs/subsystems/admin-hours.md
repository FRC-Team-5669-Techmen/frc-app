# Admin hours management

Moved verbatim from `CLAUDE.md` (The subsystems) on 2026-10-19, so `CLAUDE.md` stays short. `CLAUDE.md` links here; keep this file current in the same commit as any change to what it describes.

- **Admin hours management** (`supabase/admin_hours_management.sql` + `src/MemberHoursAdmin.jsx`/`.css`). A **per-member** staff panel embedded at the TOP of `/verify-hours` (`VerifyHoursPage`, same view as the correction queues — not a parallel screen): pick a member, then **(1)** edit (category/hours/date) or delete any of their `logged_hours` rows; **(2)** add a single `attendance_events` row (e.g. a forgotten OUT), edit an event's type/time/category, or delete a stray scan — sessions are NOT stored, they recompute from events via `sessionsFromEvents`/`buildBreakdown`; **(3)** post a labeled **hour adjustment**. All writes go through SECURITY DEFINER RPCs (RLS drops direct cross-user writes): `staff_edit_logged_hours(entry,type,hours,date)`, `staff_delete_logged_hours(entry)`, `staff_add_event(member,type,time,category,reason)`, `staff_set_event(event,type,time,category,reason)` (can flip in↔out, unlike `staff_edit_event`), reusing `staff_void_event` for delete; the attendance RPCs require a reason and write `attendance_audit`. **New `hour_adjustments(member_id, category[build/outreach/volunteer/competition], hours numeric SIGNED, reason, created_by, created_at)`** — the audit-safe way to fix totals without rewriting history; RLS **member-reads-own + staff-read-all** (per spec — so on the all-members Team board, non-staff viewers do NOT see *other* members' adjustments folded in; staff and the member themselves do), writes via `staff_add_hour_adjustment(member,category,hours,reason)`. **Adjustments fold into the category breakdown**: `buildBreakdown` gained a 5th `adjustments` param (signed, attributed to the season of `created_at`, `normAttendanceCategory`'d) — passed per-member in `HoursBoard` (the by-member page) and in `MyHoursPage`. A member sees their adjustments (category, ±hours, reason, date) in an **Hour adjustments** card on My Hours so a correction is never silent. Depends on `attendance_audit` + `is_staff()` from `session_integrity.sql`.

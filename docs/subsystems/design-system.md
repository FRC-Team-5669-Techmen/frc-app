Measured in `/_ds`: computed 56 x 205px on all 32 footer rails, 0 console errors. **`DeckStage` is the one component that is behaviour rather than appearance, and every deck mounts it EXACTLY ONCE.** It replaces the stage script that used to live in `templates/Deck.dc.html`: it renders nothing visible and paints the canvas, the letterbox and the thumbnail frames from the **ACTIVE sheet's** `--bg0` and `--edge`, repainting on every sheet change. **`--edge` is the whole job** — a deck that paints only `--bg0` leaves everything outside the stage at the browser default, so a transition flashes white, which is exactly what the generated deck did. STEPPING IS OPT-IN PER SHEET, deliberately: automatic would silently re-pace every deck already written (nine cards that landed together would cost nine key presses) and the only escape would be a per-pattern opt-out prop, which is the thing this avoids. Two zero-API doors: `data-steps` on the sheet (every pattern already spreads `...rest` onto its root), which resolves the first of the six containers that already exist (`.frc-samples`, `.frc-steps`, `.frc-pipeline`, `.frc-role-grid`, `.frc-safety-list`, `.frc-subteam-grid`), or `data-step-group` on any container the author wrote. RE-ENTRY IS BY DIRECTION, NOT MEMORY: forward entry → step 1 (the only case that starts partial, because it is the only case where the presenter is pacing), backward entry → the LAST step, and every other arrival (thumbnail, Home, End) → the LAST step, because a jump is navigation and answering a question from the floor must never show eight of nine cards missing. ONE mechanism, TWO faces: a React-element traversal (`hostChildren` splices a wrapper away, `throughHost`/`hostProps` read the element the author wrote, `containsType` type-checks through one, `cloneThroughHost` clones the author's element and keeps the wrapper) and a DOM traversal (`isHostNode`/`structuralChildren`, where `display: contents` is a computed value and is read outright rather than inferred). `slots.jsx` routes every walk through it, which is why most components needed no edit; the sites that read a child directly do — SafetySheet, SponsorTier, CalloutDrawing/JumpGrid/ProcessPipeline numbering, FieldDiagram's zone labels, SubteamStatus's badge, and DeckStage. **LOOKING THROUGH A HOST IS NOT ACCEPTING ANYTHING**: the traversal descends through wrappers the RUNTIME inserted and through nothing else, so a hazard softened into a Callout and a SafetyNote buried inside a Card are both still refused — measured both ways.

# Fixture mode

Moved verbatim from `CLAUDE.md` (The subsystems) on 2026-10-19, so `CLAUDE.md` stays short. `CLAUDE.md` links here; keep this file current in the same commit as any change to what it describes.

- **Fixture mode and the browser E2Es** (`src/dev/fixture/`, `tools/e2e/`; 2026-10-01). `npm run dev:fixture` runs the real app with `src/supabase.js` resolved to an in-memory fake that answers from a catalog generated from the frozen SQL, seeded with fictional people relative to the clock in LA; each feature plugin under `src/dev/fixture/features/` names its migration, so any of 0001 to 0012 can be on or off (0006 is data only; `/_fixture`, or `?__fx=persona:admin,mig:0001,0003,reset`); 0005's tables are not in the frozen catalog, so its plugin declares them and carries a test-only JavaScript port of the hub's rules, which proves the pages and never the SQL. It is dev only: a production build contains neither the fake nor `/_fixture`. `npm run test:checkin` (51 steps at 375 and 1440) and `npm run test:features` (nine specs, 1273 checks, both migration states, staff and non-staff) drive it, as do `tools/e2e/shoot.mjs` and the plate tools. It models no write-side RLS and no triggers (`src/dev/fixture/README.md`), and neither E2E runs in CI.

- **`src/schemaMissing.js`** (2026-10-01): the one "migration not applied yet" detector. `isSchemaMissing`, `isMissingTable`, `isMissingFunction` and `isMissingColumn` match PostgREST and Postgres error CODES (`PGRST205`/`42P01`, `PGRST202`/`42883`, `PGRST204`/`42703`, `PGRST200`, `3F000`), never message text. Every feature whose SQL has not been pasted yet degrades through it to a plain "not set up yet" state (`AnnouncePage`, `FeedbackPage`, `feedbackModel`, `ideaCerts`, `permissions`), while any other error still shows as an error.

- **Native UI timer verification (2026-10-21):** the full feature harness fixes business `Date` with Playwright `setFixedTime`, while animation, performance and retry timers run normally. `t.advanceTime` moves business time for sign-out duplicate/meeting cases; the event-family retry case waits for both actual injected failures and save completion. `node tools/e2e/clock-controls.mjs` independently checks fixed dates, running animation/timers, real button actionability and a deliberately frozen animation negative control. The original full-clock runs had different navigation/action failures, including one serial attempt; their cause remains unproven. No assertion, actionability check or navigation timeout was relaxed. Current complete suite covers 15 features with 1801 expected assertions; older counts above describe the original bundle.
